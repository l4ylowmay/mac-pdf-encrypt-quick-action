# macOS PDF 批量加密 / 解除密码快速操作

在 Finder 中选中多个 PDF，右键运行快速操作，输入并确认密码；每个文件加密并验证成功后，在原位置覆盖原件。处理完全在本机进行，不上传文件，不保存密码。

> v0.3.0 起，加密使用 **qpdf AES-256（R=6、AESv3）**，每次写入后检查实际加密参数。v0.1/v0.2 的 RC4 文件不会自动升级：请重新运行加密快速操作，输入新密码和原密码后直接升级。建议使用至少 12 位且不复用的密码。

## 安装

适用于 macOS 的 Automator（自动操作）。加密操作需要安装 [qpdf](https://github.com/qpdf/qpdf)，解除密码操作仍使用系统 PDFKit。安装了 Homebrew 后，先运行 `brew install qpdf`。脚本在 Apple Silicon 的 `/opt/homebrew/bin/qpdf` 和 Intel 的 `/usr/local/bin/qpdf` 查找依赖，不会在运行时下载软件。已在 macOS 27 环境验证，其他版本尚未实测。

1. 从 Releases 下载并解压对应的工作流 ZIP。
2. 双击 `批量加密PDF并覆盖.workflow`，按 macOS 提示安装；若打开为 Automator 编辑器，可将它复制到 `~/Library/Services/`。
3. Finder 选中 PDF → 右键 → **快速操作 → 批量加密PDF并覆盖**。
4. 输入并确认同一密码。新密码支持 1–127 位英文字母、数字、空格和英文符号，不支持中文。

新增的 **批量解除PDF密码并覆盖** 使用方法相同：在 Finder 多选已加密 PDF，右键 → 快速操作 → 批量解除PDF密码并覆盖，输入原密码即可。每次使用一个密码处理整批文件；密码错误、未加密或损坏的文件会保留原样。密码不保存在工作流中。

从源码安装也可以运行：

```sh
./scripts/install.sh
```

从旧版本升级：先在 Finder 中移走 `~/Library/Services/` 中旧的同名工作流，再安装新版；源码安装脚本不会覆盖已有工作流。替换工作流不代表已有 PDF 的加密已改变。

如果菜单中没有出现：关闭右键菜单后重新打开；在「快速操作 → 自定」中检查是否启用。安装脚本会刷新系统服务注册，无需重启 Finder。

## 行为

- 仅处理选中的 `.pdf` 文件（扩展名不区分大小写），不扫描文件夹。
- 整批文件使用同一个密码；取消输入不会修改文件。
- 已加密文件会额外请求一次原密码（整批共用），直接重新加密为 AES-256；原密码错误的文件保留原样。升级过程中不保存明文 PDF 副本。
- 每个文件先在同目录写入临时文件，检查 AES-256 参数（256 位、R=6、V=5、AESv3）、加密和锁定状态，并用密码解锁、核对页数，再通过原子重命名覆盖原件。
- 处理某个文件失败会保留该原件，继续其他文件；整批操作不是一个事务，已成功的文件不会回滚。
- 结束后显示成功数量及失败原因；不保留未加密备份，请按自己的需要预先备份。
- 需要文件和所在目录的写入权限；云盘文件应先下载到本机。

## 解除密码的实现

解除密码必须知道原密码。脚本用原密码解锁 PDF，再将页面和文档元数据放入新的 PDFDocument，生成没有加密的新文档；验证它不再加密、没有锁定且页数一致后才替换原件。页面不会转成图片。

**解除密码会重建文档，书签、文档附件及其他高级结构不保证保留；数字签名会失效。** 不适用于需要完整保留这些结构的文件。

## 实现与限制

Automator 的「运行 JavaScript」执行 JXA，通过 NSTask 调用 qpdf，使用当前的 256 位加密格式（R=6），打开密码（user password）和 owner password 使用同一非空密码。密码通过匿名管道输入 QPDFJob JSON，不出现在进程命令行参数中，也不写入密码文件。脚本不显示可能包含私人信息的 qpdf 原始诊断；qpdf 失败或警告时保留原文件。加密不额外禁止打印或复制。PDFKit 负责检查打开密码及页数。工作流和脚本均可直接审阅。

重写 PDF 可能影响数字签名、特殊表单、附件或其他高级特性；目前验证覆盖加密状态、解锁和页数，不保证这些特性的保真。覆盖时保留 POSIX 权限，但不保证保留扩展属性、ACL 或原文件时间。不要用于需要保留有效数字签名的文件。

iPhone 不能运行此 Automator 工作流；生成的是标准加密 PDF，可使用支持密码 PDF 的阅读器打开。

## 开发与验证

- `src/encrypt-pdf.js`：加密脚本源码。
- `src/decrypt-pdf.js`：解除密码脚本源码。
- `批量加密PDF并覆盖.workflow/`、`批量解除PDF密码并覆盖.workflow/`：两个可安装的 Automator 工作流。
- `scripts/build.py`：将源码同步到工作流，需 Python 3。
- `tests/smoke.sh`：在临时目录生成测试 PDF，检查实际 AES-256 参数、RC4 迁移、密码验证、验证失败时不替换原件、损坏文件保留、解除密码及两个 Automator 的输入传递；不会读取个人 PDF。

```sh
python3 scripts/build.py
./tests/smoke.sh
```

代码变更后请重新构建再提交，确保工作流与源码一致。测试中的密码仅用于自动生成的测试文件。
